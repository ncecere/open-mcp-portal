# v0.13.1 — Refreshed builder image

A patch release so the published image and `main` match exactly. It contains only these changes since [v0.13.0](v0.13.0.md):

- **Refreshed Go builder image.** The image builds from the current `golang:1.26.10` base digest (Dependabot #76). The Go version and the portal's code are unchanged.
- **Regression test for OIDC group snapshots.** An identity provider's group change takes effect at the person's next sign-in, for all of their sessions. A claim change alone cannot reach the portal. The test pins this existing behaviour; nothing changed.

**No migrations and no configuration changes.** The schema stays at `00056`, and upgrading from v0.13.0 is a plain image swap.

## Deploying

Pin the image by digest. Take it from this release's `open-mcp-portal-v0.13.1.digest.txt` and verify the signature first ([deploy.md](../deploy.md)). The example overlay carries the documented placeholder digest, so this tagged commit is exactly what `main` is.

## Evidence

Validation, publication and independent verification (four frozen full PostgreSQL suites, main CI, Kubernetes smoke, upgrade from v0.13.0 with the breaking-migration canary, load, signatures, provenance, SBOMs, CLI rebuilds and a published-image runtime check) are recorded on the [GitHub Release](https://github.com/ncecere/open-mcp-portal/releases/tag/v0.13.1). Nothing is committed after the tag, so `main` stays identical to it.
